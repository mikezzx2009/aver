# Reporting a vulnerability

Please use this repository's **Security → Report a vulnerability** flow to
report vulnerabilities privately. Include a minimal reproduction, affected
version, and impact. Never attach real API keys, passwords, session cookies,
tenant files, or production database backups.

If private reporting is unavailable, open an issue requesting a private contact
channel without including exploit details or confidential information.

Security fixes target the current `main` branch. Aver is an early, single-host
project; it has no independently audited security guarantee. Review the
deployment guide before exposing a server to other users.
